# Care Quest リスク登録簿

最終更新: 2026-07-10 JST

PMP リスクマネジメントを1人+AI体制向けに軽量化した形式で運用します。
**見直しルール**: プランナー(Fable)はバッチ立案時に本登録簿を確認し、状態の更新・新リスクの追記を行う(`docs/project-management.md` バッチ立案チェックリスト 2 と整合)。

## 状態の定義

| 状態 | 意味 |
|---|---|
| 未対応 | 対応策未実施 |
| 対応中 | 対応策が進行中または一部実施済み |
| 承認済み・〜 | リスクを受容または対応策をロードマップ化した |
| 対応済み | 対応策が完了し、再発防止の仕組みが整っている |
| 監視中 | 対応済みだが定期的な確認が必要 |
